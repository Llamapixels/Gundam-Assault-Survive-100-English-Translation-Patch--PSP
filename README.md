# Gundam Assault Survive - English Fan Translation Patch By HOLOCATT
=======================================================

Game:     Gundam Assault Survive (Japan), PSP, ULJS-00281
Patch:    Gundam Assault Survive English.xdelta  (VCDIFF / xdelta format)

This patch does NOT contain the game. You need your own dump of the Japanese ISO.

Original ISO (before patching)
  MD5: 7406e7f7b8ad4136583431bd94da759b

Patched ISO (after patching)
  MD5: edc6d03629a0813c89a5b4940fcbe9ed

How to apply
------------
Use any xdelta / VCDIFF patcher:
  - Delta Patcher or xdelta UI (Windows): choose the original ISO as the source file,
    this .xdelta as the patch, and apply.
  - RomPatcher.js (web, any system): open it, pick the ISO and the .xdelta, apply.
  - xdelta3 (command line):
      xdelta3 -d -s "Gundam Assault Survive (Japan).iso" "Gundam Assault Survive English.xdelta" "Gundam Assault Survive (English).iso"

Where it runs
-------------
  - PPSSPP: yes.
  - Real PSP / handhelds: needs custom firmware or a PSP emulator; the game program
    in the patched ISO is a decrypted EBOOT.

What is translated
------------------
  - All menus, shop, unit/pilot/parts/skill lists and descriptions
  - Mission names, briefings, objectives and every in-mission message
  - Character creation quiz, era prologues and epilogues
  - Menu images: option, shop, pause, squad, VS battle, stat labels, mission title cards
  - All 95 HOW TO help pages
  - System messages (save/load, data install, custom sound)
  Descriptions and story text are written as natural English summaries, not word-for-word.

Notes
-----
  - Start a new save if you can: pilot and squad names created with the Japanese game
    stay Japanese, because they are stored in your save.
  - The big kanji on mission start/end banners are left as-is; each already has an
    English subtitle underneath.
  - The shop's pilot stat abbreviations: ST Stamina, SH Shooting, ML Melee, AC Accuracy,
    DF Defense, RE Reaction, AG Agility, SK Skill, SN Sense.
